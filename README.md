# 陌生人的剧本杀 · 线上版

> 4 人本 · 硬核推理 · 现代悬疑

## 🌐 线上网址

**https://genevachoalan-tech.github.io/stranger-murder-mystery/**

## 📖 剧本简介

四个素不相识的人，被邀请到一间神秘的房间。一场突如其来的谋杀，将所有人卷入其中。每个人都有秘密，每个人都有动机。真相，究竟是什么？

- **人数：** 4 人（+ 1 名 DM / 主持人）
- **类型：** 硬核推理 / 本格 / 反转
- **时长：** 约 4-5 小时
- **难度：** ⭐⭐⭐⭐

---

## ✨ 功能特色

### 🏠 房间系统
- DM 创建房间，自动生成 6 位数字房间号
- 玩家输入房间号即可加入
- **断线重连：** 意外断开后重新输入房间号自动恢复角色和游戏状态
- 5 秒心跳检测，15 秒无响应标记离线

### 🎪 圆桌 UI
- 木质圆桌居中，始终可见
- DM 座位在顶部，金色 DM 徽章
- 4 个玩家座位环绕圆桌，显示写实头像、角色名、在线呼吸灯
- 空座位显示"等待加入"占位

### 🎮 完整游戏流程（14 阶段）
1. 大厅
2. 开场介绍
3. 剧本阅读（每人仅见自己剧本）
4. 信息分享（含时间线白板）
5. 第一轮线索（18 条）
6. 第一轮讨论投凶
7. 第一轮复盘
8. 第二轮线索（26 条）
9. 第二轮讨论
10. 第二轮复盘
11. 第三轮线索（8 条）
12. 最终讨论
13. 最终投凶
14. 真相大白

### 🔍 线索系统
- 52 条线索卡片，暗红晕染悬疑主题
- 实物类线索配有写实风格图片（带血匕首、智能遥控器、笔记本电脑等）
- 点击线索缩略图可放大查看
- DM 控制线索发放，玩家可公开线索

### 🗺️ 平面图
- 写实风格房间平面图，对照官方素材精确还原
- 人物座位标注清晰（史贵物 / 吴恭德 / 薛步采 / 郝庄璧）
- DM 控制发布，未发布时玩家完全看不到

### 💡 引导问题
- DM 逐个发布引导问题，控制推理节奏
- 玩家卡壳时 DM 抛出问题引导
- 未发布的问题对玩家完全不可见

### 🔊 音频系统
- **6 首 BGM**（Strange Thing / Apprehensive at Best / Basement / Insanity / Sacrifice / Silence），自动循环
- **DM 权限：** 切换曲目、播放/暂停、音量控制，操作后全端同步
- **玩家权限：** 只能调音量大小，不能切歌或暂停
- **6 种音效：** 翻页、开门、通知、线索揭示、按钮点击、悬疑 sting

### 📝 中央面板可折叠
- 线索/引导问题面板可折叠收起
- 折叠后缩成窄标签条，不遮挡圆桌
- 每个玩家可自行控制自己的视图

## 🚀 使用方法

### DM（主持人）
1. 打开线上网址
2. 点击「创建房间（DM）」
3. 验证身份后获得 6 位房间号，分享给玩家
4. 玩家加入后，在「玩家管理」中分配角色
5. 通过右侧控制面板推进游戏阶段、发放线索、控制 BGM

### 玩家
1. 打开线上网址
2. 点击「加入房间（玩家）」
3. 输入 DM 提供的 6 位房间号
4. 等待 DM 分配角色
5. 分配后即可看到自己的剧本和角色

## 💻 技术说明

- **纯单文件 HTML**，无需服务器，双击即可运行
- **PeerJS P2P** 房间同步，DM 为房间主机
- **localStorage** 断线重连恢复
- 建议使用 Chrome / Edge 浏览器，桌面端体验最佳
- 最小宽度 1024px

---

## ⚠️ 注意事项

- 房间同步依赖 PeerJS 公共 broker，需要联网使用
- DM 是房间主机，若 DM 关闭页面超过重连时间，房间状态会丢失，建议 DM 保持页面开启
- BGM 跨设备同步为尽力而为级别，可能有轻微延迟
- 建议使用自己的语音软件（Discord / 微信 / 腾讯会议等）进行语音交流
